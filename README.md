# LCS_Using_Java
# Longest Common Subsequence (LCS) in Java

## 📌 Overview
This project implements the **Longest Common Subsequence (LCS)** algorithm in Java using **Dynamic Programming**.  
The program computes both:
- The **length** of the LCS
- The **actual subsequence**

---

## ⚙️ Features
- Efficient **DP-based solution** for LCS
- Works with any two input strings
- Prints both the subsequence and its length
- Easy to run and extend
